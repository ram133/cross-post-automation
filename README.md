# CrossPost

**Post once. Publish everywhere.**

Free open-source cross-posting automation for creators.

[![Live](https://img.shields.io/badge/Live_Site-ram133.github.io%2Fcross--post--automation-22d3ee)](https://ram133.github.io/cross-post-automation/)

Write your content once. CrossPost pushes it to X, LinkedIn, Mastodon, Bluesky and more.

## Why

Most cross-posting tools are paid SaaS. CrossPost is free, local-first, and open source.

## Quick start

```bash
git clone https://github.com/ram133/cross-post-automation.git
cd cross-post-automation
pip install -r requirements.txt
python setup_secrets.py   # add your platform keys
python bot.py
```

## Features

- Single source of truth (Markdown / text)
- Multiple platforms
- Local credentials
- MIT licensed — free forever
